# 悬浮聊天与记忆优化

本轮工作范围：

- 悬浮聊天窗口的输入区、功能面板与软键盘适配。
- 主号与小号按独立身份保存聊天和记忆，模型只接收昵称。
- 小号编辑和删除，绑定关系仅用于收纳。
- 记忆页面统一搜索标签、内容、昵称和会话。
- 角色记忆列表分段加载。
- 聊天发送与重新生成的界面响应和上下文处理优化。

实现说明：

- 真实会话按账号独立保存；角色短期记忆汇总所有相关会话，以昵称区分联系人，不发送主号/小号标签。
- 新消息保存发送时的昵称，旧消息根据所属会话解析。身份编辑不会修改历史消息，小号删除保留历史资料供记忆读取。
- 记忆首页先显示角色，后台只补充数据库计数；进入详情才分批组装时间线。搜索覆盖全部已加载记录，最多渲染最近 2000 条匹配结果。
- 消息读取按会话建立位置索引，避免重复扫描其他会话。私聊不再重复组装当前会话；群聊复用已组装的角色时间线。
- 点击生成后先绘制状态，再处理上下文；长聊天记录组装按批次让出主线程。
- 悬浮聊天采用标题、可伸缩消息区域、底部输入区的布局，扩展输入区域可在窗口内滚动。

验证：类型检查、生产构建、385 个现有提示词场景、SDK/推送一致性检查、身份与索引专项回归。

测试重点：手机软键盘展开与功能面板；大数据账号发送/重试响应；小号改名、删除和切换后的记忆昵称。实际 API 等待时间仍由接口决定。

PR 保持开放，供真机测试。

## 在场访谈

- 增加用户出场、旁观、幕后代问、本人主持与灵活转换，以及轮流、全员、全员后用户回答三种采访方式。全员使用各角色自己的绑定 API 并行流式回复，用户回答后再生成角色反应。
- 支持自定义问题、场景要求、顺序讨论、录制中预约出场和逐轮推进。停止取消在途请求，保留部分文本并拦截迟到结果；草稿保留模式、状态和未发送输入，恢复不自动重新调用模型。
- 旁观者不默认写成共同受访者，主持提问与受访回答在实录和记忆中区分。旧草稿保持兼容。验证：`check-interview-live.cjs`、`check-interview-live-ui.cjs`，不调用真实 API。
- 默认接入角色最近记忆，可在策划页和录制页关闭；角色只读取自己的背景，主持人读取受访嘉宾的材料，遵循最近记忆来源与长度设置。
- 成刊不再自动写记忆或触发长期整理。刊物页可编辑摘要、勾选受访角色并手动写入最近记忆；重复写同一期仅更新所选角色，不重复增加事件计数，其他角色不受影响。

## 剧情美化

- 美化页集中壁纸、阅读面板与单行主题列表；自动模式下有壁纸移除大面板及遮罩，无壁纸保留原版，可手动保留或去掉。
- 面板关闭后分别设置用户/角色的气泡、字号、正文/对白/加粗颜色、行段间距、头像大小与形状，并提供双人预览、局部/全部重置和高级 CSS。消息间距双方共用，不新增昵称、时间选项。
- 保存后按会话生效，关闭取消未保存的修改，已有 CSS 方案保留。专项回归：`node scripts/check-story-appearance.cjs`；不调用生成 API。

## 收藏备份与窗口尺寸记忆

- 收藏 APP 支持全部、单角色及当前群组导出、导入；独立打包所需媒体，保留账号、分类、昵称和原文。重复记录默认跳过，可选覆盖；缺失媒体会提示，损坏媒体不写入空记录。
- 设置导出中的“收藏”独立可选，兼容旧版社交内容中的收藏备份。悬浮小手机自动记住上次缩放尺寸。
- 验证：`node scripts/check-favorites-transfer.cjs`，使用测试 IndexedDB 和 ZIP 验证清空原缓存后的媒体恢复、筛选、重复导入及损坏拦截，不调用生成 API。

## 生图结果下载与重复计费修复

- 服务端模式直接请求服务端或已配置的 Worker，移除先浏览器直连再回退的生成 POST，避免图片下载失败触发第二次生图。
- 图片 URL 在浏览器下载失败时交给独立下载接口，只取回原图。下载接口不接收 API Key，不调用生成端点，并限制公网地址、重定向和下载大小。
- 保存已生成但尚未下载成功的图片地址；同一配置、提示词和参考图重试或刷新后继续取原图。请求特征只保存 SHA-256，不保存明文密钥或参考图。
- 服务端已生成但下载失败时返回完成状态及图片地址，客户端保留并恢复结果；连接中断且无法确认完成状态时提示先检查 API 后台。
- 新增模拟回归：`node scripts/check-image-result-recovery.cjs`。验证过程中不调用真实生图接口。

旧版本未保留下来的失败图片地址无法自动补回，应从 API 后台下载已有图片。新代码需部署后才生效。

## 中文思考展示开关

聊天信息中新增“启用内置中文思考提示词”，按会话保存，默认关闭。开启后仅在线上私聊/群聊原请求中附加中文角色独白规则，使用当前身份昵称，不署名，不指定额外风格。独白是面向读者的角色创作文本，不代表模型真实内部推理。

开关位于“隐藏思维链”正上方，行内“详细设置”提供约 100、300、500 字三个选项，默认约 100 字，选择后立即按当前会话保存，从下次生成生效；群聊以所有角色独白合计字数为目标。字数由模型遵循提示词控制，不硬截断输出。展示继续使用现有思考区字体和排版，提示词要求自然分段。

沿用当前预设的思考标签及既有展示区域，请求内临时启用标签提取，不改写共享预设。流式预览隐藏未闭合的独白标签，正式聊天正文独立展示。关闭后恢复原有处理，历史消息保持不变；线下及自定义纯文本/结构化任务不附加本规则。

专项验证：`node scripts/check-chinese-thinking-prompt.cjs`，覆盖请求注入、默认关闭、即时读取会话配置、小号昵称、自定义标签、流式隔离及私聊群聊；不调用真实 API。

## 面板高度、矩形选脸与剧情小手机窗口

- 快捷操作面板恢复完整高度，常规上限 560 像素；短屏按可用高度收敛。保持现有宽度、预设选择和功能不变。
- 角色及用户参考图的脸部选区分别设置宽、高，支持百分比滑杆及数字输入；拖动不会越出图片。旧正方形选区继续按原来比例读取，新矩形的显示、保存及实际参考图裁剪使用同一套坐标规则。
- 剧情中打开的悬浮小手机窗口顶部增加关闭、移动、缩小、放大与大小滑杆；普通剧情和独立剧情均适用。原窗口尺寸为上限，范围为 80％至 100％；常规窗口同时保留 280×420 像素的最小可用尺寸，屏幕或键盘占用导致空间不足时优先适配当前可见区域。悬浮入口按钮不变。
- 专项检查：`node scripts/check-window-crop-geometry.cjs`，覆盖矩形保存恢复、实际画布裁剪、旧数据和窗口边界；不调用生图 API。
